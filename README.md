# C-lings

Упражнения по C: от типов и указателей до файлов, динамической памяти,
структур, графов и оптимизации. В каждой задаче есть условие, заготовка
с TODO и тесты.

Нужны GCC, GNU Make и Git.

## Как решать

1. Создай свою ветку — решения живут в ней:

   ```sh
   git switch -c my-solutions
   ```

2. Открой `exercises/00_basics/00_time.c`, прочитай условие и реализуй TODO.
3. Запусти тесты. Первый номер — тема, второй — задача:

   ```sh
   make test 0 0
   ```

4. Тесты прошли — закоммить решение и переходи к следующей задаче.

Темы идут по порядку: `00_basics`, `01_files`, `02_memory` и так далее.
Полный список — в [docs/topics.md](docs/topics.md).

Прогресс и следующая задача:

```sh
make stats
```

## Ветки

- `master` — только задачи и тесты, без решений. Её и стоит форкать.
- Твоя ветка — твои решения. Когда в `master` появляются новые задачи,
  забери их: `git merge master`.

Решения автора лежат в ветке `nikita`.
