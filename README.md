# C-lings

Маленькие упражнения по C: типы, циклы, массивы, указатели и строки.
Цель — разобраться в языке через практику. Нужны GCC и Make.

## Как решать

Открой `exercises/00_basics/00_time.c`, прочитай условие и реализуй TODO.
Проверь решение:

```sh
make test 0 0
```

Когда тесты проходят, сохрани ответ и верни чистую заготовку:

```sh
make save 0 0
make reset 0 0
```

Ответ останется в `solutions/` — его можно коммитить и переносить между
устройствами. `exercises/` снова будет содержать заготовку.

Посмотреть прогресс по всем темам и следующую задачу:

```sh
make stats
```

В командах первый номер — тема, второй — задача.
