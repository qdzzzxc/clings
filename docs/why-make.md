# Зачем здесь Make

Чтобы не писать каждый раз `gcc` с путём к файлу, флагами и именем программы,
а потом отдельно её запускать. Вместо этого:

```sh
make run 0 2
make test 0 2
```

Make передаёт команду скрипту `scripts/exercises.sh`. Скрипт находит задачу
по номерам, собирает её и запускает. Для `make test` собирается файл из
`tests/`, который подключает решение через `#include`.

Флаги компилятора заданы один раз в `Makefile`. Отдельного тестового
фреймворка нет: только GCC, Make и `assert`.
