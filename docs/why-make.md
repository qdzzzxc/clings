# Зачем здесь Make

Чтобы каждый раз не писать `gcc` с путём к файлу, флагами, именем программы
и отдельной командой запуска. Вместо этого:

```sh
make run 0 2
make test 0 2
```

Make передаёт команду небольшому скрипту `scripts/exercises.sh`. Скрипт находит
задачу, собирает её GCC и запускает результат. Для тестов добавляет `-DTEST`,
который выбирает тестовый `main` в исходнике.

Флаги компиляции задаются один раз в Makefile. Там же доступны короткие
команды для форматирования, сохранения решения, сброса и просмотра прогресса.
Никакого отдельного тестового фреймворка: только GCC, Make и `assert`.
