# Как добавить задачу

1. Выбери тему и свободный номер: например, `00_basics/07_example.c`.
   Для новой темы создай каталог вида `01_files/`. Номера тем и задач
   должны быть уникальными; используй две цифры и название после `_`.
2. Создай файл в `templates/`. За основу можно взять соседнюю задачу.
   В начале напиши условие, пример и ограничения. Добавь функции с TODO,
   демонстрационный `main` и тесты на `assert`:

   ```c
   #include <assert.h>

   int example(int value)
   {
       /* TODO: реализуйте функцию. */
       (void)value;
       assert(!"TODO: example");
       return 0;
   }

   #ifndef TEST
   int main(void)
   {
       return example(0);
   }
   #else
   int main(void)
   {
       assert(example(2) == 4);
       return 0;
   }
   #endif
   ```

3. Создай рабочую копию и проверь её:

   ```sh
   make reset 0 7
   make test 0 7
   ```

   Заготовка должна компилироваться, но проваливать тесты до решения.
   `(void)value` убирает предупреждение о неиспользуемом параметре.
4. Реализуй задачу в `exercises/`, проверь обычные и граничные случаи.
   Когда тесты проходят, сохрани ответ и верни заготовку:

   ```sh
   make test 0 7
   make save 0 7
   make reset 0 7
   make stats
   ```

5. Добавь тему в `docs/topics.md`, если она новая. Коммить шаблон, рабочую заготовку
   и решение. Makefile менять не нужно: задачи обнаруживаются автоматически.

Задача должна тренировать конкретную возможность C. Тесты и условие остаются
одинаковыми в шаблоне и решении; различается реализация функций.
