# Команды

Нужны GCC, GNU Make и Git. Для `make format` и тестов трека `algo` —
ещё clang-format: `sudo apt install clang-format`.

## Структура

```text
exercises/  — задачи: условие, заготовка с TODO, демонстрационный main
tests/      — тесты, по одному файлу на задачу
scripts/    — скрипт, который выполняет команды Makefile
```

Решение пишется прямо в файле из `exercises/`. Файлы в `tests/` менять не нужно.

Обычно задача — один файл `.c`. В теме `05_modules` задача — каталог:
в нём нужно самому создать модули и `Makefile`.

## Команды

| Команда | Действие |
| --- | --- |
| `make test 0 2` | Запустить тесты задачи |
| `make run 0 2` | Запустить саму программу (её `main`) |
| `make stats` | Статус всех задач, прогресс и следующая задача |
| `make check` | Проверить все задачи; `make check 0` — одну тему |
| `make format 0 2` | Отформатировать решение через clang-format |
| `make reset 0 2` | Вернуть заготовку задачи |

Первый номер — тема, второй — задача. Можно писать `0 2` или `00 02`.
У трека без номера вместо темы пишется имя: `make test algo 0`.

Аргументы программе передаются через `RUN_ARGS`:

```sh
make run 0 6 RUN_ARGS="10 -3 7 5"
```

## Статусы

- `PASS` — тесты прошли.
- `FAIL` — программа не собралась, тест упал или решение не уложилось
  во время. Подробности в `.build/<тема>/<задача>.log`, либо запусти
  `make test` для этой задачи.
- `SKIP` — у задачи нет тестов.

`make stats` только показывает прогресс. `make check` дополнительно
завершается с ошибкой, если что-то не прошло.

## Сброс задачи

`make reset 0 2` берёт заготовку из ветки `master`. Текущий файл перед этим
копируется в `.backups/`, так что работа не потеряется. Если ветка с задачами
называется иначе: `make reset 0 2 BASE=main`.

## Проверки при сборке

Программы собираются с `-Werror` (любое предупреждение — ошибка) и
с санитайзерами `-fsanitize=address,undefined`. Санитайзеры останавливают
программу при выходе за границу массива, переполнении знакового числа
и похожих ошибках и печатают строку, где это случилось. Без них такие ошибки
в C часто проходят незаметно.
